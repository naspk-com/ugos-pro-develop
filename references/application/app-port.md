# 应用端口

> 来源: https://developer.ugnas.com/doc/backend/application/app-port.html

应用后端服务需要声明一个固定的端口用于提供 http 服务，该端口需要在应用配置文件的 `port` 字段中声明。

系统会为每个应用分配两个独立的访问端口，分别用于 http 和 https 访问，访问路径前缀与 `proxy_path` 匹配的请求将会被转发到应用后端服务端口。

## 远程访问

应用原生支持通过 UGREENlink 进行远程访问应用，无需额外配置，系统会为每个应用分配一个专属的外网访问域名。

当使用 UGREENlink 域名访问时，系统也会自动判断当前访问客户端与 NAS 设备的网络连通性，如果客户端与 NAS 设备在同一个局域网内，则会重定向到直连域名（DNS 解析后的 IP 为设备局域网 IP）进行访问，以提供更快的访问速度。

应用可自行监听其它未在配置文件中声明的端口，但系统不会为这些端口提供代理转发服务，也不会在启动时检测这些端口是否被占用。这些端口也不能通过 UGREENlink 进行远程访问。
