# 打开方式

> 来源: <https://developer.ugnas.com/doc/backend/application/open-type.html>

应用安装后，默认会在系统桌面上展示应用图标，用户点击图标即可打开应用的前端主页面。该行为在绿联 NAS 与 HomeAgent 上均适用。默认情况下，应用前端页面会在系统桌面内以独立窗口方式打开，应用窗口的标题栏会显示应用名称。如果应用页面需要以浏览器新标签页方式打开，可以在 `project.yaml` 中设置 `open_type` 为 `tab`。

`open_type` 可选值：

- `inner`：在 UGOS Pro 系统桌面内以独立窗口方式打开（支持使用 JSSDK），推荐使用。
- `tab`：在浏览器内以新标签页方式打开。

## 打开方式对比

| 特性           | `inner`（桌面窗口）             | `tab`（浏览器标签页）       |
| ------------ | ------------------------- | ------------------- |
| **打开位置**     | UGOS Pro 系统桌面内独立窗口        | 浏览器新标签页             |
| **JSSDK 支持** | 完全支持                      | ❌ 不支持               |
| **用户认证**     | 可通过集成 JSSDK 实现 NAS 用户登录认证 | 需要应用自身实现用户账号系统及登录鉴权 |
| **用户体验**     | 桌面内可直接打开使用                | 需要跳转到浏览器新标签页        |
| **窗口控制**     | 桌面内可调整窗口大小、位置             | 浏览器标签页控制            |
