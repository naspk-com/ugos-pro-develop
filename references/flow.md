# 应用上架流程

> 来源: https://developer.ugnas.com/doc/flow.html

## 接入流程

1. 基于指南要求完成应用研发
2. 开发者完成自测
3. 邮件提交基础信息
4. 绿联商务对接沟通
5. 提交资料审校
6. 应用上架

## 补充说明

- 应用在本地设备测试通过后，将 upk 文件通过邮件发送给官方审核，审核通过后即可上架应用中心。
- 若需同时上架 NAS 与 HomeAgent，请按产品线分别打包并提交对应的 `nasync` / `homeagent` 安装包，并在申请中标明目标产品线。
- 开发者注册及应用程序上架前，必须完成真实身份认证（个人或企业），认证材料与流程详见 [开发者身份审核与管理](review/developer-identity/authentication-disclosure.md)。
