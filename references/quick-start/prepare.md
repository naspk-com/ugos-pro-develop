# 开发准备

> 来源: <https://developer.ugnas.com/doc/backend/quick-start/prepare.html>

UGOS Pro 系统是基于 Linux 内核的定制操作系统，应用开发需要基于 Linux 环境。UGOS Pro 系统支持 X86_64 和 ARM64 架构，你可以根据目标硬件平台选择对应的开发环境。

在开始开发前，你需要完成以下准备工作：

- 准备一个运行 Debian 12 的开发环境，用于编译应用后端服务、本地测试，以及生成安装包。用于安装测试或上架的 UPK 应在 Linux 上通过 `ugcli pack` 生成，以保证安装包内 Unix 文件权限正确。权限规则见 [ugcli 文件权限](../tools/ugcli.md#文件权限)。
- 从绿联云开发者平台下载开发者工具 [ugcli](../tools/ugcli.md)，并按照说明完成安装。
- 在打包测试阶段，你需要准备一台绿联 NAS 或 HomeAgent 设备，并确保设备上运行的 UGOS Pro 系统已更新到最新版本。NAS 测试机请使用 **1.13.0.0000** 及以上版本；HomeAgent 的最低固件版本请联系绿联确认。
- 按如下流程为测试设备获取开发者授权，用于应用安装测试：
  1. 邮件联系绿联官方并提供设备的序列号、MAC地址（查询方法：控制面板 > 关于本机）和管理员用户名，申请开发者授权。
  2. 将授权文件重命名为 `ugdev.sig`，并上传到设备管理员用户的个人文件夹。
  3. 若设备运行 UGOS Pro **1.16.0.0000** 及以上版本，还需打开 **应用中心 > 设置 > 应用开发设置**，点击 **授权** 按钮，完成整机授权。HomeAgent 上若菜单位置不同，以设备界面为准。

应用按产品线分发：NAS 使用 `nasync` 包，HomeAgent 使用 `homeagent` 包。详见 [产品线与机型支持](../application/product-series.md)。

> **授权更新**：自 1.16.0.0000 起，开发者授权流程有所调整，上传授权文件后须在应用中心完成整机授权。授权到期后，请在 **应用中心 > 设置 > 应用开发设置** 中上传新的授权文件以更新授权。
