# 绿联云应用中心开发者身份审核与管理

> 来源: https://developer.ugnas.com/doc/review/developer-identity/authentication-disclosure.html

为保障平台生态安全、保护用户权益并符合全球相关法律法规，绿联云应用中心对所有开发者实行严格的身份审核。开发者注册及应用程序上架前，必须完成真实身份认证。认证通过后，平台将在应用程序详情页公示开发者相关信息，便于用户和社会监督。

## 一、开发者身份认证材料说明

开发者注册时，需先填写应用程序运营者及应用程序基本信息表，并根据主体类型（个人或企业）提交相应身份认证材料。填写内容需与身份认证材料保持一致。

### 1. 个人开发者

**中国大陆地区个人开发者**：需提供身份证号码、移动电话号码用于身份验证。

**中国大陆以外国家/地区（含中国香港、中国澳门及中国台湾地区）个人开发者**：需提交以下两类文件：

- 身份证明文件，如护照、身份证、驾驶证、居留许可等
- 地址证明文件，例如带地址信息的身份证件、公共事业账单、保险单、信用卡或银行对账单等

开发者应确保所提供的身份信息与认证材料保持一致，不得使用化名、艺名或虚构身份。

### 2. 企业/组织开发者

**中国大陆地区企业/组织开发者**：需提供营业执照、统一社会信用代码用于身份验证。

**中国大陆以外国家/地区（含中国香港、中国澳门及中国台湾地区）企业/组织开发者**：需提交以下三类文件：

- 公司注册证明文件，例如注册证书、营业执照/商业登记簿、税务证明
- 公司授权代表的带照片的身份证件（授权代表指任何拥有代表该组织合法权限的人员，如首席执行官、董事、法定代表人）
- 授权证明

### 3. 注意事项

- 中国大陆以外国家/地区（含中国香港、中国澳门及中国台湾地区）的开发者可提交本地合法身份/公司证明，平台将根据所在国家/地区法规进行合规审核。
- 平台有权在必要时要求补充说明企业的实际控制人、主要经营地或法律联系点。
- 所有材料须真实、有效、最新。若开发者主体信息发生变更，应当及时更新资料并重新完成认证。若提交过时或虚假材料，将导致注册失败或账号永久封禁。
- 认证通常在提交完整材料后 3-7 个工作日内完成（如遇中国大陆地区节假日顺延），具体以平台实际审核进度为准。

## 二、应用市场平台信息披露规则

应用程序平台将在应用程序详情页披露以下信息：

| 展示信息 | 描述 |
|----------|------|
| 应用程序运营者 | 基本应用程序运营者主体名称、联系方式 |
| 应用程序基本信息 | 名称、包名、版本号、更新日期、服务类型、安装文件、备案号、适龄标识 |
| 应用程序功能 | 开发者所填写的应用程序说明 |
| 个人信息处理活动规则 | 隐私政策、未成年人个人信息保护政策（如适用）、系统权限申请情况 |
| 违规历史 | 被中国省级以上履行个人信息保护职责的部门通报或行政处罚情况（如有） |

除以上信息外，应用市场有权根据拟上架应用程序分发国家或地区的要求披露开发者提交的其他信息或资料。
